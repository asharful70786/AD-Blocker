#  Simple Ad Blocker Chrome Extension

A lightweight Chrome extension that blocks ads on websites using content script filters. Built using HTML, CSS, and JavaScript.

## 🔧 Features

 Blocks common ad elements
   Improves page load times
   Minimal UI, runs silently in the background
   100% client-side — no data is collected
